## 验证

- Windows、RTX 4070 Laptop 8 GB，G2PW 多音字模块已启用。Qt offscreen：`python -m pytest tests/test_tts.py tests/test_ui.py -q -p no:cacheprovider`，22 passed；包括本地 HTTP 请求、分句、取消、切换时释放服务、长静音重试与失败回退。
- 真实模型：通过 `AemeathLocalSpeechProvider` 合成“我在这里陪着你。有什么想说的？”，包含冷启动总耗时 20.75 秒，音频 3.60 秒。CPU 本地 Whisper base 自动识别输出为“我在这里陪着你有什么想说的”，只能辅助检查内容，不能代替人工试听。输出位于 `.local/preview/aemeath-voice/desktop-reply.wav`。
- 单次负载采样（每约 0.5 秒，GPU 数值为全机而非单进程）：启动前显存 2462 MiB；模型就绪空闲 3651 MiB、进程树内存约 1769 MiB；合成样本显存最高 4227 MiB，GPU 使用率采样峰值 75%，进程树内存最高约 3383 MiB。模型启动到就绪 13.2 秒，首轮生成 8.19 秒；机器后台负载也计入 GPU 总量。CPU 使用率以单逻辑核 100% 计，采样峰值约 1026%。并未测试同时玩游戏。
- 上游模型对多句直接合成时，2 段样本生成约 24 秒近乎静音；短句测试中同一句也出现一次长静音。已加入标点分句及长静音检测，失败自动重试一次；短句复测中其余样本 0.51–1.05 秒完成请求，单条完整回复在分句处理后成功。随机性和音色相似度仍需人工长期试听，检测无法识别所有失真、漏字或短静音。
