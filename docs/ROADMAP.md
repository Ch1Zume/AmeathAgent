# 更新计划

这里写给使用者看：接下来打算做什么、正在等什么验证。开发细节、验收标准和证据见 [任务台账](BACKLOG.md)。计划会随反馈调整，列在这里不代表一定按这个顺序完成。已经完成的变化见「更新记录」。

## 正在验证

- **杀戮尖塔 2 的新打法**：出牌伤害按力量、虚弱、易伤、敏捷、脆弱计算；按流派选牌；地图整条路线规划；每局结束自动复盘，并把经验带到下一局。目前只有自动测试，需要在真实游戏里打几局，确认算账准确、路线合理、复盘有用。
- **日程表与提醒**：手动添加或在聊天里说一声就能记下，到时间桌宠提醒。需要实际用几天，确认提醒准时、聊天里不会误加日程。
- **打包版与应用内更新**：Windows 打包版可以在「版本与更新」里一键下载新版本并自动重启。第一个打包版发布后，还要实际走一遍从旧版本更新到新版本的过程。
- **之前的功能**：主动陪伴、跨会话的往事与日常、流式聊天、屏幕观察、更快的本地语音，都还需要更长时间的实际使用来确认效果。
